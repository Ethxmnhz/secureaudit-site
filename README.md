# SecureAudit Landing

Investor-grade landing page for SecureAudit, built with React + TypeScript, Vite, Tailwind CSS, and Framer Motion.

## Run locally

Requirements: Node.js 18+ and npm.

Windows PowerShell commands:

```powershell
cd "c:\secureaudit site\secureaudit-landing"
npm install
npm run dev
```

Then open the URL shown (typically http://localhost:5173).

## Build for production

```powershell
npm run build
npm run preview
```

## Content

Copy derived from `SecureAudit.txt` highlighting:
- 16 security categories
- Behavioral validation vs. paper compliance
- Scoring, remediation, reporting
- Market gap and investor CTA

Tweak the content in `src/components` and `src/content/constants.ts`.
